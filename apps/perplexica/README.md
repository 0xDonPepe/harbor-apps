# Vane

Vane is an AI-powered answering engine.

## Local models

Install the **Ollama** app first and let Vane link to it at install (*Talks privately to*; optional). Vane then
adds an Ollama provider with Ollama's address (`http://ollama-link:11434`) by itself; pick its chat and embedding
models in Vane's settings. The models are the ones you downloaded in Ollama. Without the link, add an API provider
in the settings instead.
